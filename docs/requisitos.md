# Requisitos del sistema

## Requisitos funcionales
- RF1: Registrar y consultar estudiantes.
- RF2: Gestionar cursos (crear, editar, listar).
- RF3: Registrar matrículas de estudiantes en cursos.
- RF4: Generar reportes académicos.

## Requisitos no funcionales
- RNF1: Interfaz web sencilla (HTML, CSS y JavaScript).
- RNF2: Código versionado con Git y alojado en GitHub.
